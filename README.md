## Overview

discoDSP Corona is a resonant filter plugin offering multiple filter topologies with analog-style warmth, extensive modulation options, and tempo-synced LFO for rhythmic filtering.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **discoDSP Corona** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Multi-Mode Filter** | Low-pass, high-pass, band-pass, and notch filter modes |
| **Analog Warmth** | Non-linear saturation models the warmth of hardware filter circuits |
| **Sync LFO** | Tempo-synced LFO modulates cutoff for auto-wah and trance gate effects |
| **Modulation Envelope** | Dedicated envelope follower triggers cutoff sweeps from input dynamics |
